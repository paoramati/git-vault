id: M-2
title: Back up to a verified bundle
type: mechanic
status: ready
priority: 0
parent: E-1
labels: [agent-ok, risk:high]
invariants:
  - A file named <repo>-<timestamp>.bundle only ever exists in the destination if git bundle verify passed on it
  - The bundle contains every ref (--all)
  - If the working tree has uncommitted changes to tracked files, a matching <repo>-<timestamp>-uncommitted.patch is written
  - A failed backup leaves no partial files behind
edge_cases:
  - Destination path containing spaces
  - Destination does not exist (created)
  - Destination is not writable (exit 1, clear message)
  - Repo with no commits (exit 1, clear message)
  - Final rename fails transiently (retried up to 5 times)
  - Two backups in the same second (names must not collide)
acceptance_criteria:
  - git vault backup <dest> implemented as cmd_backup
  - Prints the path of the bundle it wrote
  - If an executable .vault/pre-backup exists in the repo, it runs first; non-zero exit aborts the backup (see F-4 for the full hook contract)
  - tests/backup.bats covers every invariant and edge case listed, and restores a written bundle with git clone to prove it
external_ref: ""
time:
  active_seconds: 0
  sessions: []
---

## Rule
Write to a dot-prefixed temp name in the destination, verify, then rename. Never write the final name directly.
