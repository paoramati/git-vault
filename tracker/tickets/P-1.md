## Problem
Every command lives in one file, so tickets that each add a different command all edit the same file and conflict at merge. Splitting by command lets independent tickets run in parallel and merge cleanly. This is prefactoring: it changes structure only, no behaviour.

## Notes
- Keep `set -euo pipefail` and Git Bash compatibility. Read .claude/skills/bash-on-windows/SKILL.md first.
- Do not implement any command here.
- Install currently copies one file. Leave install.sh working for development; W-1 will build the single self-contained file for release.
